Intrucciones
Para ejecutar el proyecto usando el docker-compose ejecute siga los siguientes pasos:
1. Descargue el proyecto en zip y descomprimalo en su maquina local
2. Entre a la carpeta del proyecto "technic.challenge"
3. Abra un command prompt desde esa ruta (CMD, Windows Power Shell, etc)
4. Ejecute el siguiente comando: docker-compose up
5. Ejecute los endpoints del CRUD de la aplicacion desde un postman (Se le esta enviando la coleccion adjunto en el correo)
